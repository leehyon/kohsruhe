## 很疲惫

这段时间在使用 AI 过程中，说不上愉快。已经过了开始的那股新鲜劲，在某些时刻，在跟 AI 来回拉扯一些问题时会变得浮躁，我以为我的意图表达够清除了，但它做出来的东西与预期相差甚远，试了好几次还是依旧，便有点泄气。即便如此，我还得说服这是自己的问题。

上周开通了 MiniMax 的 Token Plan，因为额度有限，所以想着要最大化利用起来，要做出一些有意思的东西出来。但目前为止，除了之前项目的一些小修小补，一无所获。

本来我想做一个基于地图背景的手绘旅行线路图生成 app，因为刚好前几天公司安排我分享下土耳其旅行见闻，想着生成一些图方便我讲解，同时也好做一些攻略分享到社媒平台。应该说，我试过了不下三次（推倒重来那种）但没一次的效果是令我满意的。

![image_1774509767864_0](https://images.kohsruhe.com/2026/image_1774509767864_0.png)

我大概 Vibe Coding 过程如下：
1. 先用 GPT-5.4 Think deeper 模式描述了我的需求，并把附图作为参考
2. GPT 生成针对 Coding Agent 的相关设计 Prompt 文档（包括开发要求、设计约束这些）
3. 使用 OpenCode 的 Plan 模式对文档做分析并做设计步骤和细节（模型用的是 MiniMax-2.7）
4. 使用 Build 模型执行开发任务

此外，我还使用了 [Superpowers](https://github.com/leehyon/kohstool-guide/blob/main/202603/2026-03-18-superpowers.md) 编排 AI 的工作流。但即便如此，Vibe 出来的东西还是差强人意，甚至连基本的功能都满足不了。

很疲惫。
